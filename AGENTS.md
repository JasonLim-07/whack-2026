
# Inkling — WHACK 2026

We are building Inkling, a Chinese handwriting learning web app for the incident.io hackathon track.

## Technology
- Next.js App Router, React, JavaScript, Tailwind CSS
- Next.js backend API routes
- Browser-based handwriting canvas supporting pen, mouse, touch and stylus

## Product
Users handwrite Chinese sentences or paragraphs, receive context-sensitive feedback about character recognition and grammar, and see suggestions linked to their original writing.

## Development principles
- Build incrementally. Never attempt to implement the entire MVP in one task.
- Preserve working features between milestones.
- Read docs/SPEC.md before implementing anything.
- Respect the assigned developer's files and responsibilities.
- Keep handwriting as structured strokes, not only images.
- Keep API credentials server-side.
- Do not add authentication, databases or unrelated functionality without approval.
- Run appropriate lint/build checks after changes.
- Explain which files changed and how the changes were tested.

## Team ownership
A: Handwriting whiteboard and tools.
B: AI recognition, review API and analysis.
C: UI, feedback, personalisation, integration and deployment.

## Workflow
- Work on the current Git feature branch.
- Make focused, testable changes.
- Do not commit or push unless requested.
- Do not alter unrelated components.
